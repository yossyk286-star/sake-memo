# さけメモ

お店で飲んだお酒を記録して、記録するうちに詳しくなるアプリ（PWA）。コーヒー版「まめメモ」のお酒版です。

- **記録**: 店名・種類（日本酒／ワイン／ビール／ウイスキー／焼酎／その他）・タイプ・銘柄・蔵元・産地・飲み方・味の評価・合わせた料理などを残す。入力中に「?」で用語の説明が見られる
- **メニュー撮影**: お酒のメニューを撮ると、1つずつ解説・おすすめの飲み方・合う料理を出して、フォームに入れる（Claude API を使用）
- **辞典**: 種類ごとのタイプ・飲み方・味の表現の用語集と、選び方の目安
- **好み**: 記録が5件たまると傾向を表示。産地スタンプ帳（47都道府県＋海外）、お店ごとのまとめ、気になるお酒、わたしの好み

データは端末内（IndexedDB）にだけ保存されます。設定画面からファイルに書き出し／読み込みができます。

## 開発

```bash
npm install
npm run dev   # http://localhost:3000
```

Next.js (App Router) / TypeScript。Vercel にそのままデプロイできます。

## 環境変数（メニュー撮影を使う場合）

| 名前 | 内容 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API のキー。Console で月の利用上限を設定しておく |
| `APP_PASSCODE` | 撮影機能の合言葉。他人に API を使われないためのもの |
| `MENU_MODEL` | 任意。使うモデル（既定は `claude-haiku-5-5`） |
